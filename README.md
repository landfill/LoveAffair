# 러브 어페어 · 복셀 헌정 (A Voxel Tribute)

영화 〈러브 어페어〉의 한 장면 — 햇살이 스며드는 방에서 **지니**가 피아노를 치고, **테리**가 피아노에 기대어 허밍하며, **마이크**가 두 사람을 조용히 바라보는 장면 — 을 재현한 팬 오마주 웹앱입니다.

- **모든 비주얼은 코드로 생성**: Three.js 고해상도 복셀 3D(캐릭터 약 1cm 복셀, 정점 앰비언트 오클루전, 타원체·캡슐 조각 방식) + 2D 픽셀 아트(캔버스: 창밖 풍경, 액자, 악보, 타이틀, 음표).
- **피아노 연주는 제공된 MIDI**(`src/assets/loveaffair.mid`)를 직접 파싱해 재생합니다. 건반 애니메이션과 지니의 손(2본 IK)이 노트에 맞춰 움직입니다.
- **사운드도 코드로 합성**: WebAudio 가산합성 피아노 + 리버브, 테리의 허밍(MIDI 오른손 최상성 멜로디를 따라가는 비음 포먼트 보이스).

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 정적 빌드
```

조작: 드래그 회전 · 휠 확대 · `1`~`5` 시점 전환 · `Space` 재생/정지.

비영리 팬 작품이며 영화 및 관련 권리자와 무관합니다.
